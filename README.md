# HaptyApp - Digital Twin Companion

*Other languages: [Italian](README.it.md)*

HaptyApp is the Android application designed as the digital counterpart (Digital Twin) for the [HaptyHub](https://github.com/DavideFantasia/HaptyHub) ecosystem. The application allows you to view and interact with the diagrams and graphs generated via the desktop application, acting as an interactive visual layer to overlay or place alongside 3D printed tactile models.

The app is developed in `Kotlin` and uses the spatial data produced by the ELK layout engine to ensure a perfect correspondence between the visual elements on screen and the physical reliefs of the tactile model.

## Main Features

* **Digital Twin Visualization**: Dynamic rendering of flowcharts and graphs based on the JSON coordinate files generated by the desktop application.
* **Tactile Interactivity**: Support for navigation and interaction with the diagram's nodes and edges.
* **Tablet Optimization**: Layout designed to maximize the workspace on tablet devices, facilitating the overlay with printed models.
* **Coordinate Synchronization**: Strict use of the units of measurement and margins defined in the device profile to ensure spatial consistency.

## Requirements and Build

To build and run the project, you need:

* Android Studio Jellyfish or higher.
* JDK 17.
* Android SDK 34 (API Level 34).
* An Android device (preferably a tablet) with multi-touch support.

## Installation

1. Clone the repository:

```bash
git clone git@github.com:stefanopea/haptyapp.git

```

2. Open the project with Android Studio.
3. Sync the Gradle files (KTS).
4. Run the application on a physical device or emulator.

## Usage Guide

The application automatically loads the graphical configurations to display the corresponding haptic model.

1. **Data Loading**: The app reads the `output_coordinates.json` file located in the assets folder. This file contains the (x, y) positions and dimensions of each node calculated by the AI and the ELK engine.
2. **Visualization**: Upon startup, the main interface draws the nodes (circles, squares, rhombuses) and connections following the coordinates in the file.
3. **Interaction**: The user can tap the elements on the screen to receive feedback while exploring the physical model.

# Technical Notes

* **Rendering**: Visualization is handled by custom components that interpret the hierarchies of the ELK graphs.
* **Coordinates**: Positions are expressed in relative units that are scaled in real-time based on the pixel density (DPI) and the physical screen dimensions of the tablet set in the *HaptyHub* system.
